How it works

From raw facts to a decision on record.

Gather

Project details, hazard exposure and social vulnerability in one place.

Check

Each project is tested against program rules. Missing facts show as Pending.

Rank

Weighted scores put the strongest projects first, with the reasons visible.

Decide

A named official approves, holds or ranks provisionally. The choice is logged.

Built to be trusted

Software prepares the decision. A person makes it.

Fail-closed eligibility

A project counts as eligible only when every rule passes. Unknown facts are flagged, never assumed.

Provisional ranking with a reason

Pending projects can still be ranked, but only with a written justification from a named official.

Tamper-evident record

Every determination and decision is chained to the one before it, so changes to history can be detected.

AI that summarizes, never decides

Models read documents and answer from sourced text. They cannot approve, rank or edit anything.
